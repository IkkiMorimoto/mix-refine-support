Import audio

Use the A/B folder buttons and choose a file through Files. Enable iCloud Drive, Dropbox or another provider in Files before using it.

Loudness matching

Audio can play after preparation while analysis continues. When Done appears, LUFS MATCH is available. Choose a target preset or use −/+ in Setting. Peak Guard is on by default and can lower both mixes equally to keep estimated peaks below −1 dBTP. Disabling requires confirming the clipping warning.

Playback controls

Use the bottom start and 10-second buttons to seek. SYNC is after CUE CLEAR. With SYNC off, position commands affect only the selected track.

Purchases and restoration

Optional one-time Apple support comes with customization gifts, shown after unlocking. Tap the coffee icon at the top right, then Restore purchases, using the Apple Account used for purchase. If restoration fails, open Purchase details, choose Copy details and include that technical report when contacting support. For billing or refund requests, use Apple purchase support.

Report a problem

Send the device model, iOS version, app version, file format and reproduction steps. Avoid sending private audio unless you intend to share it.
